Second Brain — local n8n

A private tool for reading the owner's knowledge and planning documents in a locally hosted n8n workflow.

What the connection does

The owner signs in with Google and authorizes a local n8n instance to read Google Drive. The configured workflow retrieves selected document content and file metadata, and downloads a spreadsheet snapshot for the owner's personal use.

n8n runs on the owner's computer. This website provides information about the connection; it does not provide a sign-in flow or access to the local application.

Google Drive access

The connection requests drive.readonly, which permits viewing and downloading files available to the authorizing Google account. The permission applies across that account's accessible Drive files. The configured workflow selects particular files to read.

This permission does not allow the app to create, edit, rename, delete, or share Drive files. The owner can run the workflow manually or enable scheduled reads in their local n8n instance.

Privacy and control

Retrieved content is processed in the owner's local n8n instance. The owner can revoke the connection through their Google Account and manage stored execution data in n8n.
